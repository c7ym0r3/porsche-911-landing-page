# Porsche 911 Turbo S Landing Page

A modern responsive landing page dedicated to the Porsche 911 Turbo S.

The project was created to practice high-quality layout development from a Figma design, focusing on clean structure, responsive behavior, and attention to visual details.

## 🌐 Live Demo

[View Website](https://c7ym0r3.github.io/porsche-911-landing-page/)

## 📌 About The Project

This project is a promotional landing page for the Porsche 911 Turbo S.

The main goal was to recreate a premium automotive website experience with:
- bold typography
- large visual sections
- modern layout techniques
- responsive design for different screen sizes
- clean and maintainable CSS architecture

## 🛠 Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- BEM methodology
- Responsive Web Design
- Git / GitHub

## ✨ Features

- Fully responsive layout
- Semantic HTML structure
- BEM-based CSS naming convention
- Adaptive navigation
- Hero section with car showcase
- Custom buttons and UI elements
- Optimized images and assets
- Smooth visual hierarchy similar to premium car websites

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/c7ym0r3/porsche-911-landing-page.git
```
Open the project folder:
```bash
cd porsche-911-landing-page
```
Open index.html in your browser.
